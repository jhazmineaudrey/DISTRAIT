# DISTRAIT [WORK IN PROGRESS]
A game about surviving the depths of the sea; all while avoiding the unsurmountable pressure placed upon you. 

## Reason for Development
Initially made for the Zone Out event of Hack Club! Although I want to continue making this as I'm pretty proud with how polished it looks, even despite it not being complete.

## Basic Controls/How to Use the Program
1. Open the game via the following link: https://ignifyris.itch.io/distrait
2. Run the game, and view it as a proof of concept for the time being.
**PRESS 'T' TO OPEN YOUR TABLET**

**TO BE ADDED IN THE FUTURE:**
- Lots of further updates! Mainly of course the minigames, as well as the other zones beyond the epipelagic zone.
